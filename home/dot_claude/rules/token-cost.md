# Token Optimization (P0-P3)

**P0**: Lead with answer. Batch tool calls. No filler.
**P1**: `Edit` > `Write`, partial `Read`, `Grep files_with_matches` first, `ToolSearch select:`.
**P2**: `jq -c`, background long commands, tight subagent prompts.
**P3**: Full `Read`, `Explore` agent, >3 parallel agents.
**Avoid**: Rehashing, restating instructions, re-reading unchanged files.
